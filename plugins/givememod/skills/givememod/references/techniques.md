# Techniques: how the best public mods solve recurring problems

Distilled from 1,313 techniques found by reading 222 mod repositories file by file (2026-10-11). Each line is one move that more than a demo needed, with the file that does it. Same move in several mods: the clearest one is linked. Code you can lift is in `blocks.md`; assets and helper files are in `resources.md`; traps are in `gotchas.md`. Behaviour reported by an author and not in the types is marked *(reported)*.

## 1. The shared band above the prompt

- **Stack, never replace.** Every mod hooks the same `AbovePrompt`; put `await next(e)` inside your own column so the others stay ([awesome-claude-mods writing-mods](https://github.com/Singh-AP/awesome-claude-mods/blob/main/docs/writing-mods.md#L160)). Test it: a stub beneath that draws a known `Text`, and assert it is still in your tree ([jaaaackieLai check.sh](https://github.com/jaaaackieLai/claude-mods/blob/main/scripts/check.sh#L5)).
- **One compositor for a pack.** A pack of mods calls `next` once, stacks its rows under it, clips each row and takes at most a third of `maxRows` ([claude-mod-pack](https://github.com/az9713/claude-mod-pack/blob/main/mod-pack/hooks/register.tsx#L948)).
- **Step aside.** Return `next(e)` when there is a survey (`props.hasSurvey`), in a subagent's view (`props.view.agentId`), or when idle for a show-while-working band (`props.isWorking`) ([holdtime](https://github.com/ItsRohith-A/holdtime/blob/main/hooks/register.tsx#L444-L449)).
- **Fit any width by dropping, not cutting.** Segments carry a priority; drop whole segments until the line fits, because a cut figure (`$1.`) misleads ([baselane band view](https://github.com/baselane-sh/mods/blob/main/engines/band/hooks/view.tsx#L14-L26)). Same facts on 2 rows when `maxRows < 10`, a framed view otherwise ([mission-control](https://github.com/charlie947/mod-maker/blob/main/plugins/mission-control/hooks/register.tsx#L170-L249)).
- **Beside, not above.** A picture can sit left of the bands below it: a row `Box` with the picture at `flexShrink={0}` ([rostech logo](https://github.com/DJPalefaceSD/rostech-mods/blob/main/plugins/logo/hooks/register.tsx#L105)).
- **No band on this surface?** VS Code and mobile draw no `AbovePrompt`: send the milestone as a toast instead ([claude-auto-handoff](https://github.com/alexknowshtml/claude-auto-handoff/blob/main/hooks/register.tsx#L324-L351)); cloud sessions have no surface at all, so hand the line to Claude through context and ask it to print it ([reply-line](https://github.com/soonavi/claude-mods/blob/main/reply-line/hooks/register.ts#L1)).

## 2. Animation without redraw storms

- **Blit, do not re-render.** Draw a `Raster` once with a `key`, then push frames with `$.ui.blit({ requestId, key, cells })`; a deny means the site is gone, so stop until the next render ([firstmate](https://github.com/kunchenguid/firstmate/blob/main/.claude/mods/firstmate-calm/hooks/register.ts#L212), [effortless](https://github.com/HeyCubit/effortless/blob/main/hooks/register.tsx#L2312-L2346)). Back off after repeated denials and send the size so a mismatch shows ([plan-progress](https://github.com/zycck/claude-mods/blob/main/plugins/plan-progress/hooks/register.tsx#L1147-L1189)).
- **Animate in a `Client`.** A `Client` module runs its own frame clock on the drawing thread (`surface.every`), so the hooks module sends nothing per frame; it posts phase changes back through `ui.message` ([Mindful-Claude](https://github.com/halluton/Mindful-Claude/blob/main/hooks/breathe.tsx#L26)). Not on the desktop *(reported: refused, CSP)*.
- **Desktop: one self-running SVG.** Use a plain image `Svg` with SMIL, not an interactive (framed) one, which reloads and blinks ([CC-Usage-Band](https://github.com/JetsonChan/CC-Usage-Band/blob/main/usage-band/hooks/register.tsx#L290-L305)). Every band redraw rebuilds it and restarts SMIL ([#100797](https://github.com/anthropics/claude-code/issues/100797)): pass the elapsed phase as `begin="-Ns"` ([frame breather](https://github.com/dvakatsiienko/frame/blob/main/home/.claude/plugin-x/mods/x-mod-breather/hooks/meter.ts#L25)) or shift every `begin` by the time elapsed ([Claude-Fables](https://github.com/henrik-thevibe/Claude-Fables/blob/main/hooks/register.tsx#L82)).
- **Tick only while something moves.** Start the timer at `turn.start`, cancel it at `turn.complete` and `session.end` ([taxi-meter](https://github.com/devbrother2024/devbrothers-mods/blob/main/plugins/taxi-meter/hooks/register.ts#L435)); or let it cancel itself when the animation ends ([usage-bars](https://github.com/pepperonas/usage-bars/blob/main/hooks/register.tsx#L99-L113)); or start it lazily from the first render so a session that never shows the band never ticks ([CC-Usage-Band](https://github.com/JetsonChan/CC-Usage-Band/blob/main/usage-band/hooks/register.tsx#L505-L512)).
- **Wake only when the text changes.** Schedule the next `$.clock.after` for the moment the shown text changes (per minute, per second only in the last minute) instead of a fixed tick ([token-weather-cache](https://github.com/youllook/ClaudeMods/blob/main/plugins/token-weather-cache/hooks/token-weather.mjs#L188)).
- **Write only on change.** The desktop redraws on every write a drawing reads: compare the would-be output and skip identical writes ([CC-Usage-Band](https://github.com/JetsonChan/CC-Usage-Band/blob/main/usage-band/hooks/register.tsx#L356-L378)); an `update` that returns the same reference writes nothing ([baselane](https://github.com/baselane-sh/mods)). Coalesce many changes into one redraw per 16 ms ([diff-review](https://github.com/stefanoshea/diff-review/blob/main/hooks/register.tsx#L61-L67)).
- **Video from a child.** A native helper prints frames; read them by hand and blit only the newest of a burst ([gb-pane](https://github.com/tylergraydev/cc-mods/blob/main/gb-pane/hooks/register.tsx#L252-L285)).

## 3. One mod, every surface

- **Three renderers.** `Raster` on the terminal, `Svg` on the desktop, one text line elsewhere, all after `next(e)` ([context-canary](https://github.com/Nachx639/context-canary/blob/main/plugins/context-canary/hooks/register.js#L504-L531)). Branch on `e.surface`, not on the element table: `resolve()` names `Svg` on the terminal too and draws nothing there ([surface-probe](https://github.com/barmoshe/bar-mods/blob/main/surface-probe/hooks/register.tsx#L104-L108)).
- **Size the desktop SVG.** Give `Svg` pixel `width`/`height`: about `bodyColumns × 8` CSS px ([Claude-Fables](https://github.com/henrik-thevibe/Claude-Fables/blob/main/hooks/register.tsx#L185)); an interactive SVG frame defaults to 300×150.
- **Pixels on the desktop.** No `Raster` there: encode the cell grid as one PNG inside an SVG with `image-rendering: pixelated` ([flow svg.ts](https://github.com/robdmac/flow/blob/main/hooks/svg.ts#L172-L229)).
- **Clicks over an SVG.** Clicks inside an SVG never reach the mod: lay real `Button`s on it with absolute positioning ([board](https://github.com/gfsaaser24/claude-code-mod-examples/blob/main/board/hooks/register.tsx#L203-L246)), or a transparent `Client` layer for taps and drags ([cutroom](https://github.com/leepokai/claude-mod-cutroom)).
- **Real images.** On kitty and Ghostty pass `Image` a file and let the terminal read it ([claude-image-view](https://github.com/jarrodwatts/claude-image-view/blob/main/hooks/register.tsx#L84)); key the image by its `path@mtime` so a changed file is not served from cache ([shot-view](https://github.com/Bearisbug/cc-mods/blob/main/shot-view/hooks/register.tsx#L56)).

## 4. Restyle what Claude Code already draws

- **Change a prop, keep the row.** `next({ ...e, props: { ...e.props, suffix } })` on `Spinner` ([claude-eta](https://github.com/hamza-siddiq/claude-eta/blob/main/eta/hooks/register.tsx#L115-L121)); swap the spinner word ([Mindful-Claude](https://github.com/halluton/Mindful-Claude/blob/main/hooks/register.tsx#L98)); `TurnDuration` and `PromptHint` the same way ([looks chrome.ts](https://github.com/theonly1me/claude-code-mods/blob/main/plugins/looks/hooks/chrome.ts#L8-L55)); unfold `ToolGroup` by setting `isExpanded` ([tool-cards](https://github.com/mustafa89/my-claude-code-mods/blob/main/tool-cards/hooks/register.tsx#L409-L412)).
- **Add to the footer.** A pill button beside the submit button by wrapping `SessionMode` ([ClaudeKeys](https://github.com/dixonSolutions/ClaudeKeys/blob/main/src/mod/register.ts#L186-L198)).
- **Hide rows.** Return a `Box` with `display: 'none'` for `ToolUse`/`ToolResult` and invalidate so rows already on screen redraw; the model's context is untouched ([firstmate](https://github.com/kunchenguid/firstmate/blob/main/.claude/mods/firstmate-calm/hooks/register.ts#L365)). Hide a slash command's own row the same way ([claude-queue-mod](https://github.com/gergesh/claude-queue-mod/blob/main/hooks/register.tsx#L199-L206)).
- **Decorate answers.** Split `AssistantMessage` text, send the plain parts through `next`, put buttons over code blocks ([copy-blocks](https://github.com/y-hirakaw/claude-code-mods/blob/main/copy-blocks/hooks/register.tsx#L273)); swap a fenced chart or diagram for an `Image` while the stored message keeps the source the model reads ([charts](https://github.com/ThomasTartrau/charts/blob/main/hooks/register.tsx#L303-L334), [claude-mermaid](https://github.com/Conte777/claude-mermaid/blob/main/mermaid-inline/hooks/register.ts#L150-L215)).
- **Clickable text in the transcript.** A `Button` there gets no clicks; a `Markdown` link with `pressableLinks` and `onLinkPress` does ([pituto](https://github.com/betoescobar46/pituto/blob/main/plugins/inline-replies/hooks/register.tsx#L216)).
- **Above the question dialog.** In the terminal a question replaces the prompt area and the band disappears; draw around `AskUserQuestion` instead, at most 12 rows ([task-line](https://github.com/muellerei/task-line/blob/main/hooks/register.tsx#L324-L338)).
- **Chat bubbles.** No `width`, `height`, `overflow` or `position` above the engine's own row, or the tree is refused: use a spacer `Box` beside the bubble ([claude-chat-bubbles](https://github.com/angeldelbiondo/claude-chat-bubbles/blob/main/chat-bubbles/hooks/register.tsx#L349-L429)).
- **Mask the screen, not the data.** For screen sharing rewrite display props of every message, tool and result row; the model still reads real values ([recording-mode](https://github.com/nateherkai/claude-code-mods/blob/main/recording-mode/hooks/register.mjs#L239-L259)).

## 5. Guards and holds

- **Fail closed.** `.catch(($, e, next) => next.called ? next(e) : { deny })`; ask again without the preview inside the catch if you like ([claude-mod-pack](https://github.com/az9713/claude-mod-pack/blob/main/mod-pack/hooks/register.tsx#L419)).
- **Ask rather than deny; merge reasons.** Run every rule, merge their reasons into one question; one deny makes the answer deny; a rule that throws becomes an ask ([baselane guard engine](https://github.com/baselane-sh/mods/blob/main/engines/guard/hooks/engine.ts#L31-L58)).
- **Nobody to ask means no.** `$.session.surfaces()` empty (headless) or a dismissed dialog: deny ([env-guard](https://github.com/seanrobertwright/claude-mods/blob/main/mods/env-guard/hooks/register.ts#L28-L35)). Serialize questions from parallel tool calls ([worktree-guard](https://github.com/thieung/claude-mods/blob/main/worktree-guard/hooks/register.tsx#L227)).
- **Three tiers.** Remind (a note in the result), ask (fails closed), block (deny that says not to work around it) ([tripwire](https://github.com/amahmood561/tripwire/blob/main/hooks/register.ts#L72-L109)).
- **Teach in the refusal.** The deny text tells the model not to retry another way and to ask the person ([guardrails](https://github.com/mishgoldenberg/claude-mods/blob/main/plugins/guardrails/hooks/register.tsx#L460)). If it still routes around: abort the turn 250 ms after the deny lands ([scope-guard](https://github.com/yash-gadodia/claude-mods/blob/main/scope-guard/hooks/register.ts#L195-L207)).
- **Once, then allow the identical retry.** Deny with the price or reason; the same call again goes through ([cache-tax](https://github.com/karanb192/cache-tax/blob/main/hooks/register.ts#L449)); tie the allowance to a fingerprint of tool, file and content so a different edit is checked again ([assertion-guardian](https://github.com/ccdwyer/assertion-guardian/blob/main/hooks/register.tsx#L117-L143)).
- **Show the blast radius.** Dry-run destructive git to list the files it would touch ([worktree-guard](https://github.com/thieung/claude-mods/blob/main/worktree-guard/hooks/register.tsx#L48)); back up first and deny if the backup fails ([freio-de-mao](https://github.com/inematds/inema-mods/blob/main/mods/freio-de-mao/hooks/register.tsx#L222)); hold behind a countdown with Cancel and Proceed, waiting inside `$` calls so the budget is not spent ([blast-radius](https://github.com/hamzafer/claude-code-mods/blob/main/mods/blast-radius/hooks/register.tsx#L27-L105)).
- **Rewrite instead of refusing.** A plain `rm a b` becomes a move into a trash folder; compound forms get a deny that says where to move files ([papelera](https://github.com/Grandullon/diariovida-mods/blob/main/plugins/papelera/hooks/register.js#L29-L52)). After rewriting a command, ask the engine's rules about the original with `$.tool.check` so `Bash(rm:*)` rules still hold ([intact-bash](https://github.com/GLEAM-Lab/intact-bash-mod/blob/main/hooks/register.js#L204)).
- **Read the shell as the shell does.** Strip quoted text, heredoc bodies and comments, but follow `bash -c`, `eval` and command substitution, so a commit message that mentions a command does not trip the guard ([merge-gate](https://github.com/hamzafer/claude-code-mods/blob/main/mods/merge-gate/hooks/register.tsx#L146-L154)). Match paths on `realPath` as well as the spelled name ([env-guard](https://github.com/seanrobertwright/claude-mods/blob/main/mods/env-guard/hooks/register.ts#L19-L25)).
- **Second lock.** Deny in `tool.call` and in `tool.check`, so a later plugin that answers the call itself still meets the verdict ([guardian demo](https://github.com/ucsandman/Agnostic-AI/blob/master/labs/claude-mods/lab/demos/guardian/hooks/index.ts#L12-L27)).

## 6. Tell the model things without the system prompt

Installed mods cannot change the system prompt where the built-in guard loads (Team or Enterprise sign-in, managed settings): `prompt.compose`, `prompt.section` and `prompt.context` of user mods are skipped there ([prismantis AGENTS.md](https://github.com/NahumLitvin/prismantis/blob/main/AGENTS.md)). These reach the model everywhere:

- **A note on a tool result** (`{ ...ran, context: [...(ran.context ?? []), note] }`): arrives exactly when it matters, invisible to the person ([plan-progress](https://github.com/zycck/claude-mods/blob/main/plugins/plan-progress/hooks/register.tsx#L1559-L1619)).
- **Context on the prompt**, put on the event you pass to `next`, not after it ([memory-lens](https://github.com/yonatangross/orchestkit/blob/main/mods/memory-lens/hooks/register.ts#L167)). One named block replaced on every check so notes do not pile up ([deploy-verify](https://github.com/yash-gadodia/claude-mods/blob/main/deploy-verify/hooks/register.ts#L98-L111)).
- **A tool description**: one sentence in `tool.describe` prevented every bad call in a measured spike; a `tool.check` bounce is the fallback ([stay-put](https://github.com/ivanvyd/ground-rules/blob/main/plugins/stay-put/hooks/register.tsx#L57-L90)). Keep it fixed for the session: a changing description breaks the prompt cache.
- **The refusal text** of a deny (section 5).

## 7. Calling a model

- **`complete` for a side job.** No history, a cheap alias, a cap, a timeout, an hourly limit, aborted by the next prompt, started with `void` so `turn.complete` never waits ([Wait What](https://github.com/az9713/claude-mod-pack/blob/main/mod-pack/hooks/register.tsx#L228)). JSON-only prompt to keep content (quiz answers) away from the main model ([know-your-claude](https://github.com/sameerthapax/know-your-claude/blob/main/brain-bar/hooks/register.js#L460-L482)).
- **`fork` for questions about this conversation.** It reuses the main cache; read `isAnswered`/`reason`; a ticket counter drops an answer that arrives after the person moved on ([aside-widget](https://github.com/oMaN-Rod/claude-code-widgets/blob/main/plugins/aside-widget/hooks/register.tsx#L136-L150)). Before the first reply and after `/clear` it answers `nothing-to-fork`: fall back to `complete` over the transcript tail ([aside](https://github.com/JayDoubleu/aside/blob/main/README.md#L55-L70)).
- **After the turn, not in it.** Schedule the call with a 0–10 ms `$.clock.after` from `turn.complete` so the hook returns at once ([mission-control](https://github.com/barmoshe/bar-mods/blob/main/mission-control/hooks/register.tsx#L195-L212)).
- **Late answers lose.** Check the run id inside the `update` callback so a slow reply cannot overwrite a newer one ([qa-guide](https://github.com/aieo-product/claude_qamods/blob/main/plugins/qa-guide/hooks/register.tsx#L593-L636)); keep one call in flight and one queued ([sportscaster](https://github.com/OneWave-AI/claude-code-mods/blob/main/sportscaster/hooks/register.tsx#L96)).
- **Write into the prompt box.** Enhance the draft with Haiku, abort on a timer, drop the answer if the person kept typing, then `$.prompt.fill` ([x-mod-stash](https://github.com/dvakatsiienko/frame/blob/main/home/.claude/plugin-x/mods/x-mod-stash/hooks/register.tsx#L355)).
- **Keep the cache warm.** A tool-less `fork` ping before the TTL lapses; stop when reads are 0 or writes reach a tenth of reads, which means the prefix broke ([cache-tax](https://github.com/karanb192/cache-tax/blob/main/hooks/register.ts#L224)).

## 8. Tools for the model

- **Register and answer yourself.** `$.tool.register` in `session.start`, answer `mcp__<plugin>__<name>` in `tool.call` with `{ result: 'text' }`; no MCP server ([read-cap](https://github.com/VedantAndhale/claude-pro-kit/blob/main/plugins/read-cap/hooks/register.ts#L153-L174)). Pull it out of ToolSearch with `isDeferred: false` or a `tool.describe` answer, or the model may never call it ([verinoda-live](https://github.com/Verinoda-Labs/verinoda-symbiosis/blob/main/claude-mods/verinoda-live/hooks/register.tsx#L893-L896)).
- **Model-driven UI.** The model calls the mod's tool to put links or a drawing on screen; the result says what was shown so it does not repeat it in prose ([wheel-finder](https://github.com/YanZiBin/wheel-finder/blob/main/plugins/wheel-finder/hooks/register.tsx#L84-L129), [diagram-mod](https://github.com/mustafa89/my-claude-code-mods/blob/main/diagram-mod/hooks/register.tsx#L146-L148)). Accept arrays sent as JSON strings.
- **Wake me later.** A tool that tells the model to end its turn; the mod watches a file or a check and wakes the idle session with `$.prompt.submit` ([wake-me](https://github.com/ivanvyd/ground-rules/blob/main/plugins/wake-me/hooks/register.tsx#L25-L128)). Replaces sleep-and-poll loops in Bash.
- **Results that steer.** End each result with the display mode or the next step; refuse misuse with the fix in the text ([taskrail](https://github.com/drolosoft/taskrail/blob/main/hooks/register.tsx#L189-L223)).

## 9. Commands and prompts

- **Register safely.** `$.command.register(…).catch(…)`: a taken name throws and kills the rest of `session.start` ([cache-clock](https://github.com/hamzafer/claude-code-mods/blob/main/mods/cache-clock/hooks/register.ts#L24-L45)).
- **Defer what waits on the session.** `$.command.run`, `$.prompt.submit`, `$.session.compact` and `/clear` are refused or deadlock inside a hook the turn waits on: answer first, then run them from `$.clock.after(0)` ([cc-mod-park](https://github.com/GGGODLIN/cc-mod-park/blob/main/hooks/register.tsx#L232-L233), [cache-keeper](https://github.com/oioi555/claude-code-mods/blob/main/plugins/cache-keeper/hooks/register.tsx#L429-L433)).
- **Hold a prompt and give it back.** `prompt.submit` returns `{ drop }` and `$.prompt.fill` restores the text; check `e.origin.kind` so background tasks and `/loop` pass ([terminal-gym](https://github.com/DrumAndCode/terminal-gym/blob/main/hooks/register.tsx#L466)).
- **A real queue.** Drop prompts typed mid-turn, release one per `turn.complete` (main loop only), pause on abort, put refused sends back at the front ([claude-queue-mod](https://github.com/gergesh/claude-queue-mod/blob/main/hooks/register.tsx#L146-L197)).
- **Who typed it.** `composer`, `bridge` and `sdk` origins are people; scheduled check-ins, task notifications and your own submits are not ([limit-parking](https://github.com/soonavi/claude-mods/blob/main/limit-parking/hooks/register.tsx#L32)).
- **Intercept built-ins.** A `command.run` hook on `exit` offers a handoff, a second `/exit` within 30 s goes through ([claude-fleet](https://github.com/Dubbus/claude-fleet/blob/main/hooks/register.tsx#L581-L600)). The model calling your command through the Skill tool skips command hooks: answer that `tool.call` with the forked result shape ([claude-share](https://github.com/Paradigm-Study/claude-share/blob/main/AGENTS.md#L55)).
- **Keys in the prompt box.** `prompt.edit` can swallow a leader chord (space space on an empty prompt) and open a picker 30 ms later ([telescope](https://github.com/danilpavlov/telescope-claude-code/blob/main/hooks/register.tsx#L484)); show argument hints in `PromptHint` only while the draft starts with your command ([usage-bars](https://github.com/pepperonas/usage-bars/blob/main/hooks/register.tsx#L357-L369)). No keybinding action runs a mod command: bind a chord to an inert engine action on a hidden `Button` ([rewrite-prompt](https://github.com/ekinertac/claude-code-mods/blob/master/rewrite-prompt/hooks/register.js#L47-L69)).
- **Macros.** Expand `;name` snippets in `prompt.submit`, skip your own management command, guard `__proto__` ([prompt-snippets](https://github.com/vincentlauriat/ModsTools/blob/main/mods/prompt-snippets/hooks/register.ts#L50-L56)).

## 10. Inside a model request (`turn.step`)

- **Observe the stream.** `const r = yield* next(e)` passes chunks through; read usage, stop reason and tools at the end ([claude-runtime](https://github.com/ucsandman/Agnostic-AI/blob/master/engine/mods/claude-runtime/hooks/index.ts#L169-L177)); time chunks for TTFT and tokens per second ([turn-telemetry](https://github.com/MiguelMachado-dev/miguel-mods/blob/main/turn-telemetry/hooks/register.tsx#L49)). Effort is visible only here ([cc-mod-park](https://github.com/GGGODLIN/cc-mod-park/blob/main/hooks/register.tsx#L236-L248)).
- **Stop a request that would overflow** by yielding a synthetic text and stop ([claude-auto-handoff](https://github.com/alexknowshtml/claude-auto-handoff/blob/main/hooks/register.tsx#L478-L519)).
- **Another engine behind a subagent.** Answer a subagent's steps from an external CLI while the engine keeps its id, transcript and list entry ([pi-agent-for-claude](https://github.com/FazalAAli/pi-agent-for-claude/blob/main/hooks/register.ts#L102)); stream for 7 s and end on a no-op tool call to start the next step past the 10 s budget ([same, L12](https://github.com/FazalAAli/pi-agent-for-claude/blob/main/hooks/register.ts#L12)).
- **Route the model** per turn from `turn.step` ([smart-model-router](https://github.com/timothylok/ClaudeCodeModsByTimLok/blob/main/smart-model-router/hooks/register.ts#L85)): each switch rewrites the prompt cache, so decide once per task.
- **Waits inside a step** go into a `$` call (a `sleep` child): `$.clock.sleep` and your own timers count against the budget ([claude-share](https://github.com/Paradigm-Study/claude-share/blob/main/plugin/hooks/register.tsx#L863)).

## 11. Context, cost and compaction

- **Pushed, not polled.** `session.measure` delivers context, cost and rate limits when they change (`e.changed`); seed once from `$.session.usage()` so the band shows before the first turn ([context-meter](https://github.com/promptadvisers/claude-mods-starter-kit/blob/main/plugins/context-meter/hooks/context-meter.mjs#L13)).
- **The /context breakdown** comes free from `$.session.usage({ breakdown: 'summary' })`; refresh after the main turn and after `session.compact` ([context-bar](https://github.com/hamzafer/claude-code-mods/blob/main/mods/context-bar/hooks/register.tsx#L34-L44)). Take live context size from `usage()`, not from a turn's summed usage ([cache-tax](https://github.com/karanb192/cache-tax/blob/main/hooks/register.ts#L490)). Per-turn cost: the difference of `usage()` at `turn.start` and `turn.complete` ([turn-receipt](https://github.com/roaringsoul404/cc-mods/blob/main/turn-receipt/hooks/register.js#L43-L81)).
- **Learn what is not reported.** The cache TTL is inferred: a hit after more than 5 minutes proves a 1-hour cache; hedge until proven ([cache-clock](https://github.com/VedantAndhale/claude-pro-kit/blob/main/plugins/cache-clock/hooks/register.ts#L43-L52)).
- **Compaction.** Steer it through `e.instructions`, replace it by returning `{ messages }`, fall back with `next(e)` on any failure ([fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction/blob/main/hooks/fast-jev.ts#L263)); start a mod's compaction after the turn from a timer, never mid-turn ([handoff-compact](https://github.com/trytofly94/handoff-compact/blob/main/hooks/register.js#L318)); a carrier message that re-seeds itself through every compaction ([pin](https://github.com/liquid1982/claude-plugins/blob/main/plugins/pin/hooks/register.tsx#L49-L69)).
- **Resume after a usage limit.** `classic.StopFailure` with a rate limit arms; a 30 s check (survives laptop sleep) submits "continue" after the reset; a typed prompt cancels ([no-limit](https://github.com/longmaba/no-limit/blob/main/hooks/register.tsx#L74-L98)).
- **Account quota with the session's login.** `$.session.authorize()` gives an opaque handle for `$.http.fetch({ auth })`; the mod never sees a token. Undocumented endpoints ([quota-pets](https://github.com/Open01277/claude-mods/blob/main/plugins/quota-pets/hooks/register.tsx#L1464-L1501)).

## 12. Subagents

## 13. State that survives reloads, `/clear` and other sessions

- **Atoms for the view, timers re-armed.** Host atoms keep values across reloads; module timers die with the module, so keep their handles in a module array the next `register` cancels, and re-arm from stored deadlines in `session.start` ([now-playing](https://github.com/hamzafer/claude-code-mods/blob/main/mods/now-playing/hooks/register.tsx#L35-L56), [ctx-handoff](https://github.com/cablate/ctx-handoff-mod/blob/main/CLAUDE.md)).
- **Self-healing timers.** A refused period ends `$.clock.every`; keep a heartbeat stamp and restart a stale timer from whatever hook runs next ([cache-keeper](https://github.com/oioi555/claude-code-mods/blob/main/plugins/cache-keeper/hooks/register.tsx#L482-L496)). Make start-up idempotent and call it from every entry point *(reported: `/reload-plugins` gave no `session.start`)* ([contentshot](https://github.com/mareksulik/contentshot/blob/main/hooks/register.tsx#L430-L448)).
- **After `/clear`.** `$.state` is wiped and `session.start` does not fire; `classic.SessionStart` is skipped where the built-in guard loads. Mirror writes and restore on the next `turn.start` ([pr-watch](https://github.com/DominickGiordano/claude-mods/blob/main/pr-watch/hooks/register.ts#L24)).
- **One key per writer.** `$.store` is one JSON file per plugin shared by every session, with no lock: give each finished run or each session its own key and fold on read ([speedrun-splits](https://github.com/ccdwyer/speedrun-splits/blob/main/hooks/register.tsx#L541)); or keep a `rev`, re-read, retry ([cc-tamagotchi](https://github.com/davidurco/cc-tamagotchi/blob/main/hooks/register.tsx#L106-L139)); serialize writes inside one process with a promise chain ([meter](https://github.com/DominickGiordano/claude-mods/blob/main/meter/hooks/register.ts#L234)).
- **Scope keys.** Prefix by project (`hash(session.root())`) ([origami](https://github.com/dullfig/origami/blob/master/hooks/origami.ts#L12-L43)) and by a per-session token so a new session does not draw the last one's data ([promote-lights](https://github.com/yonatangross/orchestkit/blob/main/mods/promote-lights/hooks/register.ts#L137)).
- **Only one session acts.** A lease in the store with heartbeats (6 s beat, 20 s lease) so one session plays the sound or runs the sweep ([claude-ambient](https://github.com/barisdemirhan/claude-ambient/blob/main/hooks/register.tsx#L30-L40)).

## 17. Building and testing

- **Pure core, thin shell.** Only `register.tsx` touches `$`; everything else is plain functions with their own tests ([taskrail ARCHITECTURE](https://github.com/drolosoft/taskrail/blob/main/ARCHITECTURE.md#how-it-works), [spare10 core](https://github.com/chrisns/spare10-mod/tree/main/hooks/core)). `validate` then still sees every call, and the footprint it prints is a trust surface you can show ([aside](https://github.com/JayDoubleu/aside/blob/main/README.md#L72-L81)).
- **Stub what you call.** A hook that calls an unstubbed `$` method is skipped and the test says so only on failure (`no implementation for <call>`); test drawings on `['terminal', 'desktop']` ([writing-mods](https://github.com/Singh-AP/awesome-claude-mods/blob/main/docs/writing-mods.md#L196)).
- **Free live test.** A mod command answers without the model, so `claude -p "/cmd" --plugin-dir <dir>` is a live check; store writes really persist ([inema-mods](https://github.com/inematds/inema-mods/blob/main/docs/COMO-FAZER-UM-MOD.md#L69)).
- **Which version is running?** Log a revision line at load; hot reload does not follow symlinks and stale loads are silent ([flow AGENTS.md](https://github.com/robdmac/flow/blob/main/AGENTS.md#development)).

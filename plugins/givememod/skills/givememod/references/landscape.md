# The mod landscape: what people build, why, and how

A decomposition of every public Claude Code mod indexed by [karanb192/awesome-claude-code-mods](https://github.com/karanb192/awesome-claude-code-mods) on 2026-10-10 (Claude Code 2.1.296 in the scanner): 3,352 entries from 1,505 repositories, 3,057 after removing exact copies, all read one by one. The full table with every link, hook list, `$` call list and reach level is [`catalog/mods.tsv`](catalog/mods.tsv). Live catalogue: <https://mods.aidojo.si/>.

How to use this file: find the job the person in front of you is trying to get done (section 2), take the mechanism that the best mods use for it, and borrow from the linked source. Section 4 lists the ideas that appear only once or twice and are worth stealing. Section 5 says what is overbuilt and what is still open.

## 1. The shape of the corpus

- **By reach**: writes files or runs processes 1,684 · reads 757 · draws and remembers only 503 · network 408. Most mods need more than drawing.
- **Most hooked events**: `session.start` 2,750 · `command.run` 2,291 · `tool.call` 1,761 · `turn.complete` 1,538 · `ui.render{AbovePrompt}` 1,335 · `ui.render{Pane}` 1,310 · `prompt.submit` 910 · `turn.start` 757 · `session.end` 593 · `turn.step` 448 · `session.measure` 387 · `ui.close` 361 · `session.compact` 307 · `PromptHint` 270 · `agent.spawn` 243 · `classic.SessionStart` 206 · `prompt.compose` 164 · `SessionMode` 157 · `ui.message` 146 · `tool.check` 144 · `AssistantMessage` 143 · `Spinner` 132 · `session.append` 130 · `ToolUse` 118 · `prompt.edit` 99.
- **Most called `$` methods**: `command.register` 2,262 · `ui.resolve` 2,215 · `state.get/set` ~1,850 · `clock.now` 1,709 · `ui.toast` 1,479 · `store.get/set` 1,301 · `process.run` 1,289 · `clock.every` 1,287 · `ui.open` 1,177 · `env.get` 1,096 · `ui.log` 1,008 · `fs.read` 959 · `clock.after` 875 · `ui.invalidate` 822 · `session.usage` 773 · `ui.status` 645 · `fs.write` 611 · `prompt.submit` 362 · `http.fetch` 357 · `model.complete` 302 · `tool.register` 263 · `prompt.fill` 256 · `ui.copy` 239 · `ui.ask` 219 · `agent.list` 216 · `ui.blit` 181 · `model.fork` 157 · `audio.play` 119 · `session.compact` 113 · `mcp.call` 58.
- **The canonical skeleton** (present in most mods): `session.start` registers a `/command` and restores `$.store` into `$.state` → one or two source events (`tool.call`, `turn.complete`, a `$.clock.every` poll) write `$.state` → one `ui.render` hook (band or pane) reads it → a toggle command, kept in `$.store`.
- **Most cloned ideas** (dozens of independent copies each): usage/limit band (60+), context bar (15+), prompt-cache countdown or keep-warm (25+), risky-command hold "blast radius" (10+ forks of the official sample), secret masking (15+), next-step buttons (12+), image paste preview (10+), done chime (8+), replay of edits (7+), idle compaction before cache expiry (6+). When a person asks for one of these, a good version already exists: start from it.

## 2. Jobs to be done

Each family: the pain → the mechanism → the best examples. Numbers in brackets are how many catalogue entries match the family by description (a mod can match several).

### 2.1 See the invisible: state awareness (≈ 900)

**Pain**: context, plan limits, cost and the prompt cache are invisible until they bite; so is what Claude and its subagents are doing right now.

**Mechanism**: `turn.complete` (main loop only) or `$.clock.every` reads `$.session.usage()` / `turn.step` usage → `$.state` → one-line `AbovePrompt` band or `PromptHint` tail; detail in a `/command` pane. Zero model tokens.

- Context: official [token-weather](https://github.com/hamzafer/claude-code-mods/tree/main/mods/token-weather), stacked by `/context` category [context-bar](https://github.com/hamzafer/claude-code-mods/tree/main/mods/context-bar), metaphors: weather [weather-widget](https://github.com/oMaN-Rod/claude-code-widgets/tree/main/plugins/weather-widget), tide [tide](https://github.com/Hula-Hoop-AI/supermods/tree/main/plugins/tide), brain [working-memory](https://github.com/Hangghost/learning-hacker-claude-mod/tree/main/plugins/working-memory), moon and dawn [night-feast](https://github.com/theonly1me/claude-code-mods/tree/main/plugins/night-feast), boss health bar [boss-widget](https://github.com/oMaN-Rod/claude-code-widgets/tree/main/plugins/boss-widget), canary that dies when a CLAUDE.md rule is broken [context-canary](https://github.com/Nachx639/context-canary).
- Limits and cost: [usage-meter](https://github.com/hamzafer/claude-code-mods/tree/main/mods/usage-meter) [usage-band](https://github.com/JetsonChan/CC-Usage-Band/tree/main/usage-band) [desktop-statusline](https://github.com/centminmod/claude-plugins/tree/master/plugins/desktop-statusline) [usage-bars](https://github.com/pepperonas/usage-bars) pace and forecast [usage-forecast](https://github.com/harshitmywork17/claude-mods/tree/main/plugins/usage-forecast) [headroom](https://github.com/vihrea1337/headroom), in lattes [latte-meter](https://github.com/baselane-sh/mods/tree/main/plugins/latte-meter) or chai [chai-meter](https://github.com/ShriD5/claude-mods/tree/main/chai-meter), as a taxi meter [taxi-meter](https://github.com/devbrother2024/devbrothers-mods/tree/main/plugins/taxi-meter), fuel gauge [gas-gauge](https://github.com/DJPalefaceSD/rostech-mods/tree/main/plugins/gas-gauge), burning fuse [burn-meter](https://github.com/OneWave-AI/claude-code-mods/tree/main/burn-meter).

### 2.2 Spend less: tokens, cache, context (≈ 780)

**Pain**: every cold resume re-bills the whole context; big tool output and long sessions waste the window; the wrong model or effort burns the plan.

**Mechanisms**:
- Keep the cache warm or compact before it lapses: forked keep-warm ping [cache-warmer](https://github.com/paulbkim-dev/claude-code-cache-warmer), guard the cold send once [cache-tax](https://github.com/karanb192/cache-tax) [cold-cache-guard](https://github.com/mediavee/cold-cache-guard), compact after N idle minutes while warm [idle-compact](https://github.com/takahirom/takahirom-claude-code-marketplace/tree/main/plugins/idle-compact) [idle-compact](https://github.com/benredmond/idle-compact/tree/main/idle-compact), hold system sleep while keeping warm [cache-keeper](https://github.com/oioi555/claude-code-mods/tree/main/plugins/cache-keeper).
- Ask before throwing the cache away (`/model`, `/effort`, MCP changes) [cache-guard](https://github.com/mako-code/gobworks/tree/main/mods/tuning/cache-guard).
- Shrink tool output before the model reads it (`tool.call` → `await next` → rewrite result, full text saved to a file): per-command filters [bash-diet](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/bash-diet), quiet flags added *before* the command runs [cmd-diet](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/cmd-diet), head/tail with errors kept [output-diet](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/output-diet), a model judges big outputs [winnow](https://github.com/GhalebDweikat/winnow).
- Do not pay twice: answer a repeated `Read` of an unchanged file from a cache [costclaw-live](https://github.com/ucsandman/Agnostic-AI/tree/master/labs/claude-mods/prototypes/costclaw-live) [read-cache](https://github.com/mako-code/gobworks/tree/main/mods/tuning/read-cache), send only changed hunks on re-read [delta-reads](https://github.com/mako-code/gobworks/tree/main/mods/tuning/delta-reads), stop whole-file reads past 1,000 lines and offer an outline tool [read-cap](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/read-cap).
- Trim what rides on every request: unused tools behind ToolSearch [tool-diet](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/tool-diet), unused skills to names only [skill-diet](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/skill-diet), per-folder MCP instructions [ctx-slim](https://github.com/Bearisbug/cc-mods/tree/main/ctx-slim), mute injected reminders [reminder-filter](https://github.com/mako-code/gobworks/tree/main/mods/tuning/reminder-filter).
- Compaction without amnesia: structured handoff instead of summary [handoff-compact](https://github.com/trytofly94/handoff-compact), keep exact facts after compaction [compact-keeper](https://github.com/VedantAndhale/claude-pro-kit/tree/main/plugins/compact-keeper), pinned notes re-sent after every compaction [pin-note](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/pin-note) [pin](https://github.com/liquid1982/claude-plugins/tree/main/plugins/pin), save point before `/compact` [quicksave](https://github.com/pourya7/claude-code-mods/tree/main/quicksave), compaction at task boundaries rather than at the wall [taskcut](https://github.com/wasd96040501/taskcut), verbatim pruning by a decision model [fast-jev-compaction](https://github.com/tamaratran/fast-jev-compaction), fold old output to disk behind stubs with `hydrate()` [origami](https://github.com/dullfig/origami).
- Route model and effort: subagent model by label [switchboard](https://github.com/hamzafer/claude-code-mods/tree/main/mods/switchboard), pin Explore to Haiku [explore-model](https://github.com/rlorenzo/ai-coding-setup/tree/main/mods/explore-model), effort per prompt [effortless](https://github.com/HeyCubit/effortless) [effort-auto](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/effort-auto), effort prefix `^max` in the prompt [effort-prefix](https://github.com/mako-code/gobworks/tree/main/mods/prompting/effort-prefix), switch only when it beats the cache rewrite [autotune](https://github.com/mako-code/gobworks/tree/main/mods/tuning/autotune).
- Budgets: stop at a cost or plan threshold [budget-guard](https://github.com/Arunjay4213/claude-mods/tree/main/plugins/budget-guard), keep a reserve for yourself [spare10](https://github.com/chrisns/spare10-mod), tell every agent to wrap up near the limit [usage-wrapup](https://github.com/DaKev/usage-wrapup), ask before paid third-party APIs, granted for one hour [vigia-api](https://github.com/inematds/inema-mods/tree/main/mods/vigia-api).

### 2.3 Stay safe: guards (≈ 400 guards, ≈ 60 secret maskers)

**Pain**: one `rm -rf`, force push, `DROP TABLE`, leaked key or publish can cost days.

**Mechanism**: `tool.call` (or `tool.check`) matched on the tool, decide *before* `next(e)`, deny with an instruction or hold with `$.ui.ask` / a pane; `.catch` so the guard fails closed. Paths by `realPath`.

- Hold and show what it would change: official [blast-radius](https://github.com/hamzafer/claude-code-mods/tree/main/mods/blast-radius) and its forks, with trash/backup/cancel options [freio-de-mao](https://github.com/inematds/inema-mods/tree/main/mods/freio-de-mao) [delete-guard](https://github.com/Tihi321/claude-mods/tree/master/plugins/delete-guard), "what a yes would lose" measured from git under the permission dialog [stakes-widget](https://github.com/oMaN-Rod/claude-code-widgets/tree/main/plugins/stakes-widget), a code to arm and a LAUNCH button [launch-codes](https://github.com/OneWave-AI/claude-code-mods/tree/main/launch-codes).

### 2.4 Keep Claude honest: coaches, gates, evidence (≈ 250)

**Pain**: confident claims without runs, loops on the same failure, tests weakened to pass, drive-by refactors, stale docs.

**Mechanisms**:
- Feed facts into the tool result right after an edit or commit (`tool.call` → `await next` → append to the result), so the model fixes them now: callers of a changed signature [contract-watch](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/contract-watch), docs made stale by a commit [doc-drift-watch](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/doc-drift-watch), env vars missing from `.env.example` [env-sync](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/env-sync), lockfile not updated [lockfile-sync](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/lockfile-sync), missing i18n keys [i18n-watch](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/i18n-watch), config file no longer parses [config-parse](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/config-parse), lint and type errors of the edited file [red-squiggle](https://github.com/ccdwyer/red-squiggle) [lint-feedback](https://github.com/mako-code/gobworks/tree/main/mods/autopilot/lint-feedback), PR review threads for the file being edited [review-ghost](https://github.com/ccdwyer/review-ghost), unresolved symbols [verinoda-live](https://github.com/ozcinax-star/verinoda-symbiosis/tree/main/claude-mods/verinoda-live).
- Break loops: fifth edit of the same file → "state the root cause" [edit-loop](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/edit-loop), same failing call twice → change approach [loop-guard](https://github.com/arasovic/claude-code-mods/tree/main/loop-guard) [tool-coach](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/tool-coach) [spiral-stop](https://github.com/0xGondarxyz/claude-code-mods/tree/main/spiral-stop), a test that both passed and failed on the same code → rerun, do not change code [flaky-memory](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/flaky-memory).
- Claims vs evidence: "tests pass" with nothing run this turn [anti-cheat](https://github.com/pourya7/claude-code-mods/tree/main/anti-cheat) [verify-before-claim](https://github.com/vincentlauriat/ModsTools/tree/main/mods/verify-before-claim), confident prod claims without a query [claim-check](https://github.com/tylergraydev/cc-mods/tree/main/claim-check), cited files and lines that do not exist [footnotes-widget](https://github.com/oMaN-Rod/claude-code-widgets/tree/main/plugins/footnotes-widget) [spotcheck](https://github.com/ivanvyd/ground-rules/tree/main/plugins/spotcheck), results that went stale after later edits [proof-decay](https://github.com/ccdwyer/proof-decay), a fix must first make a test fail [prove-it](https://github.com/pourya7/claude-code-mods/tree/main/prove-it).
- Guard the tests: weakened assertions, new skips, gutted files [test-guard](https://github.com/Justmalhar/awesome-claude-mods/tree/main/mods/test-guard) [assertion-guardian](https://github.com/ccdwyer/assertion-guardian) [jev-test-guard](https://github.com/mako-code/gobworks/tree/main/mods/jev/jev-test-guard).
- Scope: drift away from the request flagged or held [scope-guard](https://github.com/theonly1me/claude-code-mods/tree/main/plugins/scope-guard) [jev-scope](https://github.com/mako-code/gobworks/tree/main/mods/jev/jev-scope) [scope-guard](https://github.com/yash-gadodia/claude-mods/tree/main/scope-guard), a receipt "you asked for one thing, here is everything" [scope-creep-receipt](https://github.com/mofocm/scope-creep-receipt/tree/main/plugin), pinned goal with drift count [goal-anchor](https://github.com/tylergraydev/cc-mods/tree/main/goal-anchor) [aim](https://github.com/Singh-AP/awesome-claude-mods/tree/main/mods/productivity/aim).

## 3. Craft patterns of the best mods

- **Zero tokens by default.** The most-starred mods state it in the description: no model calls, no context added. Model calls are opt-in and gated (main loop only, only after a turn that changed something, a `/x off` switch).
- **Quiet unless relevant.** Bands appear only when there is something to say (context over 70% [context-gauge](https://github.com/vincentlauriat/ModsTools/tree/main/mods/context-gauge), a PR open [promote-lights](https://github.com/yonatangross/orchestkit/tree/main/mods/promote-lights), a turn running) and yield to surveys.
- **Display-only vs model-facing is explicit.** Many mods say "display only: nothing reaches the model" ([prompt-time](https://github.com/KilimcininKorOglu/claude-code-mods/tree/main/plugins/prompt-time) [json-pretty](https://github.com/baselane-sh/mods/tree/main/plugins/json-pretty) [path-shorten](https://github.com/baselane-sh/mods/tree/main/plugins/path-shorten)); the ones that change what the model reads say so and keep it to one line.
- **Packs and dependencies.** One hazard or feature per mod, then a bundle plugin that lists them as `dependencies` ([guard-pack](https://github.com/baselane-sh/mods/tree/main/plugins/guard-pack), the beads family [bead](https://github.com/baselane-sh/mods/tree/main/plugins/bead)–[beads-today-bar](https://github.com/baselane-sh/mods/tree/main/plugins/beads-today-bar), the SDD family [sdd-analyze-gate](https://github.com/fib1618agent/claude-mod-speckit/tree/main/mods/04-analyze-gate)–[sdd-traceability](https://github.com/fib1618agent/claude-mod-speckit/tree/main/mods/07-traceability)).
- **Fallback for every surface.** A pane that cannot be placed falls back to the band ([blast-radius](https://github.com/hamzafer/claude-code-mods/tree/main/mods/blast-radius)); terminal-only elements get a text or Svg version on desktop; where nothing draws, the command's text carries the facts.
- **Steal from the engine.** Read the todo list from the `TodoWrite`/`TaskUpdate` tool calls, the plan from `ExitPlanMode`, usage from `$.session.usage()`, effort from `turn.step`, instead of asking the model.
- **Fix, don't just block.** Repair malformed MCP arguments against the schema [mender](https://github.com/pourya7/claude-code-mods/tree/main/mender), rewrite `rm` to trash [rm-to-trash](https://github.com/irfanfaraaz/claude-kit/tree/main/mods/rm-to-trash), fix Windows paths and quoting before Bash runs [shell-guard](https://github.com/youllook/ClaudeMods/tree/main/plugins/shell-guard) [intact-bash-mod](https://github.com/GLEAM-Lab/intact-bash-mod), steer `npm` to the repo's package manager [pm-guard](https://github.com/narrowstacks/claude-code-mods/tree/master/pm-guard).
- **Metaphor sells a gauge.** Weather, fuel, tide, taxi meter, boss HP, Minecraft hearts: the same number, read at a glance.

## 5. Crowded vs open

**Crowded** (build only with a clear twist): usage/limit bands, context bars, cache timers and keep-warm, blast-radius forks, secret maskers, next-step buttons, done chimes, pets, snake.

**Under-served** (good targets for a new mod):
- Guards that are both fail-closed (`.catch`) and symlink-safe (`$.fs.stat(p, { resolve: true }).realPath`): most published guards are neither.
- Composer integration (`prompt.edit`, 50 ms budget): only ~100 mods use it; live linting of the prompt, inline macros, cost preview of what is about to be sent.
- Desktop-first visuals: most drawing mods target the terminal; desktop has no `Raster`/`Image`, so pixel work there needs `Box` runs or `Svg`.
- Per-dialog, throwaway mods: almost every catalogue mod is a general product. A mod written for one conversation (this task's checklist, this migration's progress, this bug's repro status) and thrown away after is the gap this skill exists to fill.
- Cross-tool parity: guards that must hold in Codex too remain settings hooks; a mod that mirrors them and shows the state is rare.

Пишешь /givememod.Получаешь мод под задачу.

Скилл для Claude Code. Смотрит, что ты делаешь, собирает маленький мод под это, подгружает его на лету в терминале или в десктопе и доводит, пока не понравится.

УстановитьЗвезда на GitHub

Зачем

Моды Claude Code это маленькие плагины внутри Claude Code: полоса над промптом, боковая панель, уведомление, удержание вызова инструмента, команда, которая отвечает мгновенно. За несколько недель появилось больше 3000 публичных, и почти все это общие продукты.

Задаче нужно что-то меньше и короче: полоса для этой миграции, гард для этого деплоя, наблюдатель за этими тестами. givememod пишет такой мод за минуту и знает всё, до чего додумались авторы тех 3000.

Как работает

  1. Читает ситуациюЧто ты попросил, характер работы (план, много файлов, долгие задачи, опасные команды, сабагенты), состояние сессии, проект, твои любимые моды.
  2. Выбирает один модСамый маленький полезный мод. По /givememod собирает его сразу и называет запасной; без запроса, на долгой задаче, предлагает одной строкой: что показывает, где и сколько стоит.
  3. Собирает из шаблонаОдиннадцать проверенных шаблонов и 29 блоков, по правилам, которые проверяет загрузчик, в папку модов сессии.
  4. Проверяетclaude plugin validate и claude plugin test до того, как ты его увидишь.
  5. Подгружает на летуВ первый раз Claude Code спросит, включить ли hot reload для сессии; дальше каждая правка появляется, когда заканчивается ответ.
  6. Оставляет понравившиесяСкажи «оставь»: мод уходит в папку скиллов, грузится в каждой сессии без установки, и в похожей задаче его предложат первым.

Плюсы и минусы

Плюсы

  • Ноль токенов по умолчанию: шаблоны не вызывают модель и ничего не добавляют в контекст.
  • Каждый мод проходит validate и тесты до того, как ты его увидишь.
  • Разовые моды уходят вместе с сессией, оставленные идут с тобой дальше.
  • Проверяет чужие моды до установки: до чего дотягиваются, сколько стоят, что настораживает.

Минусы

  • Моды работают с твоими правами; гард на Bash это напоминание, а не песочница.
  • Первый мод в сессии попросит включить hot reload.
  • Моды рисуют только в терминале и во вкладке Code десктопа; в VS Code и claude -p хуки работают без отрисовки.
  • Мод с хуком на Bash ломает Bash у сабагентов в worktree, пока это не починят в Claude Code.

Установка

  1. Добавь маркетплейс (в любом терминале)

    claude plugin marketplace add timoncool/givememod

  2. Установи плагин

    claude plugin install givememod@givememod

  3. Перезапусти Claude Code и в любой сессии

    /givememod

Что можно сказать

  • /givememod
  • /givememod полосу плана над промптом
  • /givememod держи rm -rf, пока не подтвержу
  • /givememod гоняй npm test каждые 20 секунд

Вопросы

Что такое мод Claude Code?

Плагин с модулем хуков, который работает внутри Claude Code. Он умеет рисовать полосу над промптом, открывать панель, показывать уведомления и строку статуса, держать вызов инструмента до твоего ответа, добавлять команды без хода модели и давать Claude свои инструменты.

Это тратит токены?

Сборка мода это один обычный ход Claude. Сами моды не вызывают модель, если не попросить, и ничего не добавляют в контекст.

Где живут моды?

Разовый мод лежит в папке модов сессии и убирается вместе со старыми сессиями. Оставленный копируется в ~/.claude/skills/<имя> (или в .claude/skills проекта) и грузится оттуда в каждой сессии.

В десктопе работает?

Да, во вкладке Code в Claude Desktop. Установи плагин один раз из терминала, и скилл появится в десктопных сессиях.

Мод безопасен?

Мод работает с твоими правами. Каждый шаблон маленький и читаемый, гарды закрываются при сбое, а чужой мод скилл проверяет до загрузки.

Можно поделиться модом?

Да. Папка с файлом маркетплейса рядом с plugin.json ставится командой /plugin install <мод> --marketplace <владелец>/<репо>.

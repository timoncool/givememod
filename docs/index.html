Say /givememod.Get a mod for this task.

A Claude Code skill. It reads what you are doing, builds the small mod that fits it, loads it live in the terminal or the desktop app, and tunes it until you like it.

InstallStar on GitHub

Why

Claude Code mods are small plugins that run inside Claude Code: a band above the prompt, a side pane, a toast, a hold on a tool call, a command that answers instantly. More than 3,000 public ones appeared in a few weeks, and almost all are general products.

What a task needs is smaller and shorter-lived: the bar for this migration, the guard for this deploy, the watcher for this test suite. givememod writes that one in a minute and knows what the 3,000 others already figured out.

How it works

  1. Reads the situationWhat you asked, the shape of the work (a plan, many files, long jobs, risky commands, subagents), session state, the project, your favorites.
  2. Picks one modThe smallest mod that helps. /givememod builds it at once and names the runner-up; unasked, on a long task, it is offered in one line with what it shows, where and what it costs.
  3. Builds it from a templateEleven tested templates and 29 building blocks, written by the rules the loader enforces, into the session's mods folder.
  4. Checks itclaude plugin validate and claude plugin test before you see it.
  5. Loads it liveThe first time, Claude Code asks to enable hot reloading for the session; after that every change appears when the reply ends.
  6. Keeps the ones you likeSay "keep it": the mod goes to your own local marketplace and is proposed first the next time a similar task comes up.

Where it works

TerminalClaude Code 2.1.287+: bands, panes, status line, toasts, held tool calls, commands.
Desktop appThe Code tab of Claude Desktop, 2.1.286+: the same mods, drawn as cards, panes and toasts.
ElsewhereHooks also run in claude -p, the SDK and the VS Code panel, where nothing is drawn.

Good and not so good

Good

  • Zero tokens by default: the templates make no model calls and add nothing to the context.
  • Every mod is validated and tested before you see it.
  • One-off mods go away with the session; the ones you keep follow you.
  • Reviews third-party mods before you install them: reach, cost, red flags.

Not so good

  • Mods run with your permissions; a guard on Bash is a reminder, not a sandbox.
  • The first mod of a session asks you to enable hot reloading.
  • Mods draw only in the terminal and the desktop Code tab; in VS Code and claude -p the hooks run without drawing.
  • A mod that hooks Bash breaks Bash in worktree subagents until Claude Code fixes it.

Install

  1. Add the marketplace (any terminal)

    claude plugin marketplace add timoncool/givememod

  2. Install the plugin

    claude plugin install givememod@givememod

  3. Restart Claude Code, then in any session

    /givememod

Questions

What is a Claude Code mod?

A plugin whose hooks module runs inside Claude Code. It can draw a band above the prompt, open a pane, show toasts and a status line, hold a tool call until you answer, add commands that answer with no model turn, and give Claude tools.

Does it cost tokens?

Building a mod is one ordinary Claude turn. The mods themselves make no model calls unless you ask for one, and they add nothing to the context.

Where do the mods live?

A one-off mod lives in the session's mods folder and is cleaned up with old sessions. A kept mod is copied to ~/.claude/givememod/mods and listed in a local marketplace.

Does it work in the desktop app?

Yes, in the Code tab of Claude Desktop. Install the plugin once from a terminal; the skill is then there in desktop sessions too.

Is a mod safe?

A mod runs with your permissions. Every template is small and readable, guards fail closed, and the skill reviews any third-party mod before you load it.

Can I share a mod I like?

Yes. A folder with a marketplace file beside plugin.json is installable with /plugin install <mod> --marketplace <owner>/<repo>.
